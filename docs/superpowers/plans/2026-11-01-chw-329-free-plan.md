# CHW-329 Free plan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A coach signs themselves up with no card and coaches up to `FREE_CAP` clients for free, whether or not Creem billing is configured; above the cap they are offered a paid plan.

**Architecture:**
- **Settings.** A new `FREE_CAP` env setting (config `fitpal.free_cap`, default 0 = off).
- **Free status.** When the setting is above 0, `Entitlement` gives every coach without a writable licence the status `free`: writable, capped at `FREE_CAP`. Admins stay exempt.
- **Default unchanged.** When it is 0, today's rules stand: billing off means `unlicensed`, unlimited. Self-hosted copies and the test suite keep working as they do now.
- **What `FREE_CAP` turns on.** It opens self-serve signup and adds `free` to `Plans::offered()`. It also switches on the app's plan UI (`plansOn`), which today follows `config.billing` alone.
- **The trial goes.** The app stops promising a 14-day trial; Free replaces it.

**Tech Stack:** Laravel 13 / PHP 8.4, Pest; React 19, Zustand, Vitest (happy-dom).

**Spec:** `docs/superpowers/specs/2026-11-01-creator-coach-design.md` §2 cost 1, §5 phase 1. **Issue:** CHW-329.

     * The plans on sale, for the app: Free first when FREE_CAP is set (no periods: nothing to
     * buy), then each paid tier with its cap and the periods it can be bought for, in tier order
     * — those only while billing is on.
     *
     * @return list<array{plan: string, cap: int, periods: list<string>}>
     */
    public static function offered(): array
    {
        $out = self::freeCap() > 0 ? [['plan' => 'free', 'cap' => self::freeCap(), 'periods' => []]] : [];
        if (! self::billingOn()) {
            return $out;
        }
        $products = self::products();
        foreach (self::CAPS as $plan => $cap) {
            $periods = array_values(array_filter(self::PERIODS, fn ($p) => isset($products[$plan][$p])));
            if ($periods !== []) {
                $out[] = ['plan' => $plan, 'cap' => $cap, 'periods' => $periods];
            }
        }

        return $out;
    }
